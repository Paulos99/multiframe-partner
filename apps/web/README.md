# MultiFrame Проблемомер

Веб-прототип MVP для **StP MultiFrame**: создаёт спрос на акустический комфорт при выборе натяжного потолка и ведёт к калькулятору MultiFRAME / заявке.

Это **не** калькулятор материалов и **не** инженерный расчёт звукоизоляции.

Продуктовая дисциплина: [CHECKLIST.md](CHECKLIST.md) · [PRODUCT_SPEC.md](PRODUCT_SPEC.md).

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

Base path для GitHub Pages: `/multiframe-problemomer/`.

Ожидаемый URL после деплоя:

`https://paulos99.github.io/multiframe-problemomer/`

## Скоп MVP

**В скоупе**

- Только потолок; шум сверху через перекрытие
- Только бескаркасная система StP MultiFrame
- Мастер из 7 экранов
- Экспертная качественная модель (без фейковых ΔRw / ΔLnw)
- Аудио до/после (демо-заглушки с бейджем «демо»)
- Дисклеймеры; CTA с payload (`schemaVersion: 1`)

**Вне скоупа**

- Стены, перегородки, полы, Polyblock, каркасные системы
- Вопрос про этаж
- Лабораторные гарантии дельт в дБ (модель — ориентир по полевым замерам на объектах, `field_in_situ`)

## Экраны

1. Старт — эмоциональный хук + «Начать»
2. Комната — тип, площадь м², опционально плита
3. Сценарии шума (мультивыбор)
4. Текущее состояние — комфорт + тип шума + «почему»
5. До/после — обычный потолок vs MultiFrame
6. Аудио — услышать разницу
7. Профиль + CTA: расчёт (`?area=`), консультация на stp-multiframe.ru (`#section-partner`)

## Заглушки

## Деплой

При пуше в `main` GitHub Actions (`/.github/workflows/deploy.yml`) собирает Vite-приложение и публикует артефакт через official Pages actions.

В настройках репозитория: Settings → Pages → Source = **GitHub Actions**.
