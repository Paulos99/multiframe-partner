# Обновление 1.2.5

- Аналитика больше не показывает несуществующих сотрудников. Причина: при работе с сервером экран аналитики всё равно подмешивал демо-базу браузера (`mf_partner_db_v5`) — демо-сотрудников, демо-комнаты и демо-события. Поэтому у сети без партнёров в «Сотрудниках» были Елена Крылова, Игорь Лебедев и другие, а в воронке «Комната». Теперь с сервером аналитика строится только по данным сервера, у всех ролей. Демо-данные остались только в сборке без сервера и в явном демо-режиме. Старая демо-база на устройствах просто не читается, чистить её не нужно. Данные на сервере не менялись.
- У администратора StP при пустой сети вместо выбора «Партнёр: Все» написано «Пока нет подключённых кабинетов партнёров».
- Рейтинг сотрудников: в карточке больше нет «0» и «За период нет данных», когда рядом стоят ненулевые цифры. Первая кнопка периода «Выбранные даты» показывает, что действует период из шапки; «Месяц/Квартал/Год» его временно заменяют.
- «Обратная связь»: администратор StP может удалить обращение кнопкой «Удалить» с подтверждением. Сервер: `DELETE /feedback/:id` (только администратор StP, иначе 403), фото обращения удаляются из хранилища, в журнал пишется `feedback_deleted`.
