# MultiFrame Partner 1.2.1

## Исправления
- **Кабинеты (админ):** при пустом списке с сервера больше не подставляются демо-компании из локального хранилища браузера. Раньше после очистки прода в «Кабинетах» могла оставаться «Потолки Столицы», а удаление давало «Партнёр не найден».
- То же для списка сотрудников при работе с API: пустой ответ сервера не заменяется локальным демо.
