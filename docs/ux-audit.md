# UX-аудит кабинета партнёра

Проверено в демо-режиме `?demo=1` на локальном seed (без облачного API): роли **admin**, **owner**, **sales**, **measurer**, **crew** компании «Потолки Столицы». Ширины **390×844** и **1280×800**, плюс тёмная тема (`mf_theme=dark`) на телефоне.

Крупные новые сценарии (напоминания по срокам, маршруты, серверный поиск) здесь только как предложение. В PR вошли P0 и простые P1, без смены API и правил доступа.

## Анимации

Сделано на пакете `motion` (MIT), с `prefers-reduced-motion`:

1. Вход: появление карточки и встряска при ошибке.
2. `Button`, «Сохранить объект» и «Отправить КП»: нажатие, загрузка, короткий успех.
3. Список объектов: появление строк, смена бейджа статуса.
4. KPI аналитики: count-up.
5. Скелетоны загрузки аналитики и пустого списка.

Источники идей и лицензии указаны в комментариях к `apps/web/src/partner/motionBits.tsx` и `apps/web/src/ui/Button.tsx`. Код с платных витрин не копировался.
