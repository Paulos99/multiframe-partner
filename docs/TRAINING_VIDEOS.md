# Обучающие видео ролей

В разделе «Обучение» (вкладка «Материалы») первыми, выше папок, стоят обучающие видео в формате 16:9, с афишей. По кнопке «Смотреть» открывается то же окно просмотра, что и у остальных файлов в материалах. Встроенные ролики играют в исходном качестве 1920×1080. Сам ролик не скачивается, пока окно не откроют.

Кто какое видео видит, решает администратор StP: у каждого видео есть роли видимости («Кто видит»), как у папок и файлов материалов. Сервер отдаёт роли только видео, открытые для неё. Администратор StP видит все видео с отметкой «Видят: …» и может:

- добавить видео («Добавить видео»: сначала выбрать роли, потом видеофайл);
- поменять, кто видит видео («Кто видит»);
- удалить любое видео, в том числе встроенный ролик роли («Удалить», с подтверждением).

Переход со старого правила. Раньше каждый из четырёх встроенных роликов был жёстко привязан к своей роли и не удалялся. При первом чтении материалов после обновления ролики добавляются в библиотеку с ролью, за которой были закреплены (владелец — `owner`, менеджер — `sales` и т. д.), у менеджера StP видео по-прежнему нет. В хранилище это записывается вместе с первой правкой администратора (флаг `materialVideosSeeded` в документе платформы), поэтому удалённый ролик не возвращается. Файлы встроенных роликов остаются в `public/videos`: удаление убирает только запись из библиотеки.

| Роль в кабинете | Ключ в настройках | Файл |
| --- | --- | --- |
| Владелец компании | `owner` | `role-owner` |
| Менеджер по продажам | `sales` | `role-sales` |
| Замерщик | `measurer` | `role-measurer` |
| Монтажник | `crew` | `role-crew` |

## Где что лежит

- Файлы встроенных роликов: `apps/web/src/partner/roleVideos.ts` (файл, заголовок, длительность, описание, версия). Названия и описания повторены в `packages/shared/materialsLib.js` (`BUILTIN_TRAINING_VIDEOS`) для сервера; тест `roleVideos.test.ts` следит, чтобы они совпадали.
- Кто что видит: роли видимости в `packages/shared/materialsLib.js` (`effectiveRoles`, `visibleMaterialNodes`).
- Файлы: `apps/web/public/videos/<файл>.mp4` и афиша `apps/web/public/videos/<файл>.jpg`.
- Карточка на экране: `apps/web/src/partner/RoleVideoCard.tsx`.
- Папка `videos/` не входит в офлайн-кэш приложения (`vite.config.ts`): ролики грузятся при просмотре.

## Как заменить ролик (после перезаписи)

Нужны Node.js и `ffmpeg`. Из папки `apps/web`:

```
npm run video:swap -- owner /путь/к/новому/role-owner.mp4
```

Вместо `owner` подставьте нужный ключ из таблицы (`owner`, `sales`, `measurer`, `crew`). Необязательно: `--poster-at=5` — секунда кадра для афиши (по умолчанию 1).

Скрипт:

1. проверяет, что видео 16:9;
2. приводит к 1920×1080 H.264 (crf 20) с быстрым стартом (`+faststart`), обычно 12–40 МБ на ролик (ролики до 3 минут);
3. снимает афишу `.jpg`;
4. обновляет длительность и поднимает `version` в `roleVideos.ts`. Адрес получает `?v=…`, поэтому ни браузер, ни кэш сервера не покажут старое видео.

Дальше: открыть «Обучение» под этой ролью, нажать воспроизведение, закоммитить `public/videos/*` и `roleVideos.ts`.

Вручную то же самое: положить `.mp4` и `.jpg` с тем же именем в `public/videos`, в `roleVideos.ts` поправить `duration` и увеличить `version` на единицу.

## Ограничения (проверяются тестами)

- ролик не тяжелее 55 МБ;
- формат 16:9;
- описание файла (`moov`) в начале mp4, иначе ролик не начнёт играть до полной загрузки;
- у каждой роли свой файл.

## История правок озвучки

- **v4 (owner / measurer / crew):** исправлено ударение в «натяжно́й / натяжны́м» (раньше TTS ставил ударение неверно). В озвучке для Edge TTS `ru-RU-DmitryNeural` на ударную гласную ставится знак U+0301; на экране и в субтитрах написание без ударения. Сборщик: `promo-mf/scripts/roles/gen-voice-v3.py` + `fix_natyazh_stress.py`. Ролик менеджера (sales) не затронут — в текущей озвучке слова с этим корнем нет.
