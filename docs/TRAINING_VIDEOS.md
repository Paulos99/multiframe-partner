# Обучающие видео ролей

В кабинете у каждой роли в разделе «Обучение» (вкладка «Материалы») первым пунктом, выше папок, стоит обучающее видео этой роли. Оно в формате 16:9, с афишей. По кнопке «Смотреть» открывается то же окно просмотра, что и у остальных файлов в материалах. Сам ролик не скачивается, пока окно не откроют.

Кто что видит:

- владелец, менеджер, замерщик и монтажник — свой ролик;
- администратор StP — все четыре ролика подряд, только для просмотра;
- менеджер StP — роликов нет (отдельного видео для этой роли не делаем).

Удалить ролик из кабинета нельзя: в карточке нет кнопок удаления и замены, на сервере для них нет запросов. Заменяются ролики только кодом (ниже).

| Роль в кабинете | Ключ в настройках | Файл |
| --- | --- | --- |
| Владелец компании | `owner` | `role-owner` |
| Менеджер по продажам | `sales` | `role-sales` |
| Замерщик | `measurer` | `role-measurer` |
| Монтажник | `crew` | `role-crew` |

## Где что лежит

- Единственная настройка «роль → файл»: `apps/web/src/partner/roleVideos.ts` (файл, заголовок, длительность, описание, версия).
- Файлы: `apps/web/public/videos/<файл>.mp4` и афиша `apps/web/public/videos/<файл>.jpg`.
- Карточка на экране: `apps/web/src/partner/RoleVideoCard.tsx`.
- Папка `videos/` не входит в офлайн-кэш приложения (`vite.config.ts`): ролики грузятся при просмотре.

## Как заменить ролик (после перезаписи)

Нужны Node.js и `ffmpeg`. Из папки `apps/web`:

```
npm run video:swap -- owner /путь/к/новому/role-owner.mp4
```

Вместо `owner` подставьте нужный ключ из таблицы (`owner`, `sales`, `measurer`, `crew`). Необязательно: `--poster-at=5` — секунда кадра для афиши (по умолчанию 1).

Скрипт:

1. проверяет, что видео 16:9;
2. приводит к 1920×1080 H.264 (crf 20) с быстрым стартом (`+faststart`), обычно 12–40 МБ на ролик (ролики до 3 минут);
3. снимает афишу `.jpg`;
4. обновляет длительность и поднимает `version` в `roleVideos.ts`. Адрес получает `?v=…`, поэтому ни браузер, ни кэш сервера не покажут старое видео.

Дальше: открыть «Обучение» под этой ролью, нажать воспроизведение, закоммитить `public/videos/*` и `roleVideos.ts`.

Вручную то же самое: положить `.mp4` и `.jpg` с тем же именем в `public/videos`, в `roleVideos.ts` поправить `duration` и увеличить `version` на единицу.

## Ограничения (проверяются тестами)

- ролик не тяжелее 55 МБ;
- формат 16:9;
- описание файла (`moov`) в начале mp4, иначе ролик не начнёт играть до полной загрузки;
- у каждой роли свой файл.
