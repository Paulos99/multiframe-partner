# ADR-003 — Запрет вертикальных стеков; вкладки/маршруты вместо «супа»

- **Статус:** Accepted (`rev-gate-a-approved-20261022`)
- **Дата:** 2026-10-22

## Контекст

`SalesHome` / `OwnerHome` на одном табе стеком: WorkToday + EntryPoints + ObjectsPanel + CommercialPanel. На mobile это нечитаемо; на desktop смешивает четыре работы. ux-audit чинил тач-таргеты, но не архитектуру внимания.

## Решение

Один viewport — одна работа:

- Home = inbox + один primary CTA;
- каталог проектов — отдельный экран;
- сделка/КП — в контексте проекта (вкладка/маршрут);
- инструменты — fullscreen с возвратом.

Вкладки или вложенные маршруты предпочтительнее длинного скролла из независимых панелей.

## Отвергнутые альтернативы

| Альтернатива | Почему нет |
|--------------|------------|
| Оставить стек, «просто добавить якоря» | Не снимает когнитивную нагрузку; ломает AC «понятно без инструктажа» |
| Dashboard из виджетов KPI+список+КП | Для полевых ролей избыточно; бренд/продукт — операционная платформа, не BI-старт |
| Модалки поверх стека | Прячет проблему |

## Следствия

- Gate C прототипы проверяют отсутствие стека на golden path.  
- D4: каждый экран — один primary purpose.
