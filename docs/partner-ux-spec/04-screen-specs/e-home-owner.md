# E-home-owner — Home владельца компании

**Revision:** `rev-gate-b-draft-2` · **Gate B · NOT approved** · aliases: часть `E-home`

## Кто / зачем
Owner: вмешательство в сделки/назначения + быстрый старт проекта; обзор «что требует решения».

## Первый viewport
1. «Сегодня · Компания»  
2. Inbox: сделки без next action, назначения без assignee, blockers, deals paused  
3. Primary CTA: **Новый проект**  
Secondary (не в первом экране-стеке): Staff · Компания (nav)

## Приоритет inbox
1. Open blockers (crew)  
2. Accepted без assignee crew / без tech-ready  
3. Paused deals  
4. Projects без активной Deal при наличии deferred  
5. Staff invites pending (если есть)

## CTA → destination
| CTA | Destination |
|-----|-------------|
| Новый проект | E-inquiry |
| Inbox item | E-project / E-project-deal / E-room-install |
| Staff (nav) | [E-staff](./e-staff.md) |
| Компания (nav) | [E-org](./e-org.md) |

## Скрыто
Admin network partners; training как sales KPI; чужие org.

## Состояния
loading / empty («Создайте первый проект») / error / offline / first-time (CTA Новый проект + short tip Staff) / expert (inbox-first).

## Mobile
Тот же inbox; Staff/Компания — secondary nav.

## AC

- AC-HO-02: нет стека аналитики+tools+КП на home
