# Обновление кабинета до v1.2.0 (с v1.1.0)

Для разработчиков, которые ведут сервер. Код на сервере не правится: ставится готовая метка `v1.2.0`
(она лежит на ветке `main` репозитория https://github.com/Paulos99/multiframe-partner).

Рабочий сервис Павла: `https://partner.stp-multiframe.ru` (не путать с продом Болдекса `stp-multiframe.ru`).

## Что нового

- **Очередь PDF:** снять застрявшие документы; плашка на ПК пишет «На этом компьютере», не «На телефоне».
- **Аналитика:** тихое фоновое обновление без повторной анимации; плавный переход заголовка на «Фото отчёты» и «Журналы».
- **Календарь** — третий вид во вкладке «Проекты» (Канбан / Календарь / Список); старые ссылки `#calendar` ведут туда.
- **Кабинеты** (бывш. «Партнёры»): раздел **Администраторы StP** — несколько админов сети.
- **Воронка «Путь клиента»:** ясная модель этапов, компактные строки, подписи «Не дошли до следующего этапа».
- **«Сегодня»:** напоминание пройти занятие в тренажёре с кнопкой «Перейти к занятию».

## Что сделать до установки

1. **Резервная копия** хранилища (см. docs/handover/BACKUPS.md): `platform-v2.json`, `analytics-events*.json`,
   `activity-log*.json`, `login-state.json` и бакет с фото и документами.
2. **Новых обязательных переменных окружения нет.**
3. **Миграции данных нет.**

## Установка

```bash
cd /opt/multiframe-cabinet
git status --short
./deploy/release.sh v1.2.0
```

Или через GitHub Actions: workflow **Deploy production**, поля `tag=v1.2.0`, `confirm=deploy-prod`.

Скрипт проверит `/cabinet/version.json` (`"id":"v1.2.0"`) и `/cabinet-api/health` (`"ok":true`).

## Проверка

1. `curl -fsS https://partner.stp-multiframe.ru/cabinet/version.json` → `"id":"v1.2.0"`.
2. `curl -fsS https://partner.stp-multiframe.ru/cabinet-api/health` → `"ok":true`.
3. Вход администратором StP; раздел «Кабинеты» и «Администраторы StP»; «Сегодня» с напоминанием о занятии.
