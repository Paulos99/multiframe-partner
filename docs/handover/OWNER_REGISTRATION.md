# Регистрация владельцев по ссылке

Владелец компании-партнёра регистрируется сам по ссылке из письма. Кабинет создаётся сразу, владелец входит и работает без ожидания. StP подтверждает или отклоняет заявку позже, в разделе «Кабинеты».

## Ссылка для письма

```
https://partner.stp-multiframe.ru/cabinet/#/register
```

На стенде: `https://paulos99.github.io/multiframe-partner/#/register`. На странице входа есть кнопка «Зарегистрироваться», она ведёт туда же.

## Что заполняет владелец

Имя, фамилия, название компании, город (из справочника), логин, пароль и повтор пароля. Все поля обязательны.

- Логин уникален без учёта регистра и без пробелов. Если занят — «Такой логин уже занят. Придумайте другой.»
- Пароль по общим правилам кабинета (`packages/shared/passwordPolicy.js`): не короче 8 символов, без пробелов по краям.
- Защита от рассылок: скрытое поле-ловушка `website` (человек его не видит) и предел частоты по адресу — 5 новых кабинетов в час, попыток с ошибками — до 30 (`REGISTER_IP_LIMIT`).

После отправки создаются компания (цены по умолчанию, как при создании админом) и пользователь с ролью «Владелец». Владелец сразу оказывается в кабинете.

## Что видит владелец

- Над содержимым кабинета — тихая плашка «Регистрация на проверке у StP». Работе она не мешает и пропадает после подтверждения.
- На «Сегодня» — карточка «Добавьте менеджера»: открывает «Компания → Сотрудники» с уже выбранной ролью «Менеджер». Карточка исчезает, когда в компании появляется хотя бы один менеджер. Менеджер сам добавляет менеджеров, замерщиков и монтажников.

## Что видит администратор StP

- В меню: «Кабинеты · N», где N — число новых заявок. На «Сегодня» — карточка «Новые заявки на регистрацию» с кнопкой «Разобрать заявки».
- В разделе «Кабинеты» — блок «Новые заявки»: компания, имя и фамилия, город, логин, дата заявки. Кнопки «Подтвердить» и «Отклонить».
- «Отклонить» спрашивает подтверждение и необязательную причину. После отклонения владелец и все сотрудники компании не могут войти; при входе они видят «Регистрация отклонена StP» и причину, если она указана. Уже открытые сеансы закрываются при следующем запросе.
- Отклонённые заявки лежат под кнопкой «Отклонённые: N», их можно подтвердить позже — вход откроется снова.
- В списке «Кабинеты сети» у таких компаний метки «заявка на проверке» или «отклонён».

## Как это хранится

Статус заявки — поле `registration` в записи компании в `platform-v2.json`:

```json
{ "status": "pending | approved | rejected", "source": "self", "firstName": "…", "lastName": "…",
  "submittedAt": "…", "decidedAt": "…", "decidedBy": "<id админа>", "reason": "…" }
```

У компаний, заведённых админом, поля нет: для них ничего не меняется. Журнал действий: `register_owner`, `approve_registration`, `reject_registration`, `register_trap` (сработала ловушка).

Код: `apps/api/registration.js`, маршруты в `apps/api/index.js`; интерфейс — `RegisterScreen.tsx`, `RegistrationRequests.tsx`, `registration.ts`. Проверки: `apps/api/registration.test.js`, `apps/web/src/partner/registration.spec.ts`, `apps/web/e2e/owner-registration.spec.ts`.
