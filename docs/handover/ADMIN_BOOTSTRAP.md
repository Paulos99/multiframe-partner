# Первый администратор

В пустом хранилище нет ни одной учётной записи, демо-пользователей тоже нет (при `NODE_ENV=production` и без `DEMO_SEED`).
Первого администратора создаёт сам сервис из переменных окружения:

```
ADMIN_BOOTSTRAP_LOGIN=<логин, например stp.admin>
ADMIN_BOOTSTRAP_PASSWORD=<случайный пароль не короче 10 символов, без пробелов по краям>
ADMIN_BOOTSTRAP_NAME=<имя и фамилия живого человека, например Иван Петров>
```

Порядок:
1. Сгенерируйте пароль: `openssl rand -base64 18` (не отправляйте его в чат и почту; передайте владельцу лично или через менеджер паролей).
2. Впишите три переменные в `deploy/.env`, запустите/перезапустите сервис.
3. Откройте `https://stp-multiframe.ru/cabinet/`, войдите, **смените пароль** (в профиле пользователя).
4. Удалите `ADMIN_BOOTSTRAP_*` из `deploy/.env` и перезапустите (`FORCE=1 ./deploy/release.sh <текущая метка>`).
5. Дальше администратор создаёт компании-партнёры (раздел «Партнёры»), владельцы компаний создают своих сотрудников.

Что нужно знать:
- В `ADMIN_BOOTSTRAP_NAME` не пишите слова «Админ», «Администратор» (и пустое значение, по умолчанию «Администратор»): система считает их названием роли, а не именем, и подставляет демонстрационное имя. Имя можно потом поменять в профиле.
- Создание срабатывает **только когда документ платформы ещё не существует**. В уже работающую систему новых админов
  этой переменной не добавить — используйте раздел «Партнёры» или сброс пароля от имени другого администратора.
- Если переменные не заданы, а хранилище пусто, сервис отвечает на вход сообщением с подсказкой (503), демо-админа не создаёт.
- Потерян пароль единственного администратора: сначала сделайте копию `platform-v2.json` ([BACKUPS.md](BACKUPS.md)). Затем
  в этом документе у записи администратора замените `passwordHash` на новый bcrypt-хеш
  (`cd apps/api && node -e "import('bcryptjs').then(b=>console.log(b.default.hashSync(process.argv[1],12)))" 'новый-пароль'`)
  и увеличьте `sessionVersion` на 1 — старые сессии этой записи станут недействительными. Пока в системе есть второй администратор,
  такой правки не нужно: он сбрасывает пароль в разделе «Партнёры».
- Пароли: минимум 10 символов; после 10 неверных попыток запись блокируется на 15 минут; вход ограничивается и по адресу клиента.
- Админ — единственная роль с доступом ко всем компаниям. Заведите минимум двух админов для замены и храните учётные данные раздельно.
