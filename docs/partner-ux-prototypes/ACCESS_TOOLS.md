# Gate C — карта доступа: Проблемомер и Калькулятор

**Уточнение владельца:** согласованный вид/логика инструментов сохраняются. Это **отдельные standalone-инструменты** для всех сотрудников. PM перед Calc **не** обязателен. Gate A/B бизнес-решения не пересматриваются.

## Кто

| Роль | Проблемомер | Калькулятор |
|------|-------------|-----------|
| sales · owner · measurer · crew · admin | да | да |

Desktop: секция **Инструменты**. Mobile: hub **Инстр.** с двумя входами (или прямые пункты — см. nav в прототипе).

## Маршруты (любая залогиненная роль)

| | URL |
|--|-----|
| Проблемомер | `#/tools/pm` |
| Калькулятор | `#/tools/calc` |
| Bind (только при сохранении) | `#/tools/bind` |

## Правила

1. Старт без проекта / сделки / комнаты.  
2. PM⇄Calc независимы; handoff опционален.  
3. Привязка к проекту/комнате только на Save (права pick/create в демо-орг.).  
4. Быстрый доступ к инструменту ≠ доступ к чужим данным вне орг. фикстур.  
5. Без редизайна внешнего вида без отдельного запроса владельца.
