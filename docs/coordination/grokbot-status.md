# Координация — GrokBot «MultiFrame Партнёр»

Обновлено: 18 октября 2026, 13:45 по Москве.

Бот «MultiFrame Партнёр» (в отчётах Codex — «Грокбот») ставит задачи облачным агентам Cursor, проверяет PR и деплой. Не мёржит в `main` без согласия Павла.

## Текущая задача — принята

Перенос партнёрских материалов из Яндекс.Диска в Яндекс.Облако.

- Цель: бакет `multiframe-partner-data`, префикс `materials/`.
- Источники: маркетинг, продажи, пакет для рассылки дилерам, дизайнерам и монтажникам, рекомендации по мотивации менеджеров.
- Дубли убираются по хэшу содержимого. Каждый уникальный файл хранится один раз, но полное дерево папок с Диска сохраняется в списке.
- Файл-список: `materials/manifest.json` в бакете. Для каждого файла в нём раздел, аудитория, путь на Диске, название, тип, размер, хэши и ключ в хранилище.
- Данные вне `materials/` не трогаются: `platform-v2.json`, `analytics-events.json`, `docs/`.
- Бакет остаётся приватным.
- Статус: загрузка идёт. Результат и число файлов допишу сюда после завершения.

Следующий шаг после загрузки — задача агенту Cursor на подраздел «Обучение → Материалы для продаж». Файлы этой задачи и приёмка — по `materials-acceptance.md`. Агент работает в модуле материалов: `MaterialsPanel.tsx`, `materialsClient.ts`, `MaterialStubView.tsx`, `apps/api/materialsRoutes.js`, `materialsLib.js` и их тесты и стили. Если затронет общие файлы, они будут перечислены здесь до начала работы.

## Очередь

1. Подстановка сохранённой площади при открытии калькулятора для объекта. Объём минимальный, как в `codex-status.md`.
2. Заказ из нескольких помещений с сохранением старых записей.
3. Версии исходных данных расчёта и сметы.
4. Ответственные по этапам, следующее действие и срок.
5. Экраны ролей, история, согласованные статусы.
6. Отделение демо-событий от аналитики.

Исполнитель для пунктов 1–6 закрепляется отдельно через отчёты.

## Ограничения

- Коммерческая политика: рабочей ссылки нет. Вместо неё заглушка «Материал готовится к публикации», без кнопки открытия, видна пока только STP и владельцу.
- Через текущий API в кабинет загружаются файлы до 2 МБ. Большие файлы загружаются прямо в хранилище, без обрезки и пропусков.
- Демо-данные и записи в хранилище не сбрасывать и не удалять.
- Внутренние материалы и материалы для руководителя не открываются автоматически всем ролям.
- Секреты не попадают в репозиторий и в задачи агентов.

## Координация

Основное место обмена — `docs/coordination/` в репозитории. Папка «MultiFrame личный кабинет партнёры» на рабочем столе бота — вспомогательная копия, а не главный источник. Отчёт Codex я не изменяю.
