# Перенос материалов: границы и приёмка

Назначение заказчика: бот «Мультифрейм партнёр» (Грокбот) ведёт перенос из Яндекс.Диска в Яндекс.Облако и подключение файлов к разделу «Обучение», используя агентов Cursor для необходимых изменений кода. В разговоре задача подтверждена; черновик для агента пока готовится. Codex ведёт аналитическую проверку, параллельных изменений обучения нет.

## Структура источников

1. Внутренняя коммерческая политика дистрибьютора — исходная ссылка недоступна, ожидается рабочая ссылка или файл. Отсутствие не блокирует остальные разделы.
2. Материалы маркетинга.
3. Материалы продаж.
4. Пакет для рассылки дилерам, дизайнерам и мастерам монтажа — не обозначать автоматически как пакет для владельцев квартир.
5. Рекомендации по мотивации менеджеров.

Верхний уровень четырёх последних источников доступен; полная пофайловая проверка ещё не выполнена. Ссылки предоставлены заказчиком в разговоре. Содержимое внутренних документов не публикуется в этом отчёте.

## Проверяемый результат

- Реестр исходных файлов с результатом каждого переноса: перенесён, дубль, ошибка либо ожидается доступ. Размеры и версии фиксируются по фактическим данным.
- Файлы находятся в облачном хранилище, метаданные папок и файлов доступны кабинету. Существующие материалы сохраняются.
- В разделе обучения отображаются согласованные разделы и вложенные папки; файл открывается или скачивается из рабочего кабинета.
- Проверены как небольшой документ, так и самый крупный поддерживаемый файл; неподдерживаемые размеры явно перечислены.
- Внутренние условия дистрибьютора и материалы управления не становятся автоматически доступны всем ролям: аудитория отдельно согласуется.
- Проверены роли и поведение после перезагрузки. Развёртывание подтверждено на опубликованном сервисе, а не только наличием коммита.

## Ограничение текущего кода

Согласно README проекта, загрузка материалов через текущий API ограничена 2 МБ; большие файлы требуют другого пути загрузки. Этот предел необходимо учесть до реализации, не обрезая и не пропуская файлы молча.

Точные занятые файлы и подтверждение запуска агента ожидаются в отчёте исполнителя. Подготовка черновика не означает, что перенос уже запущен или выполнен.
