# UI-пакет

Ветка: feat/ui-package. База: origin/main c16961d.

Объём: общая Motion-система, канбан комнат с существующими фильтрами и API, скелетоны, стабильный скроллбар, компактное обучение без изменения текстов, профиль с логином, текущим паролем и приватным аватаром.

Облачные операции выполняет MultiFrame Партнёр. Деплой, данные, бакеты и ключи из этой ветки не изменяются. Точные требования интеграции будут в описании PR «Нужно от Yandex Cloud».

Проверки: lint, typecheck, unit, e2e и production build. В исходной базе отсутствуют npm-команды lint/unit/e2e; они добавляются в рамках пакета. Готовность подтверждается результатами проверок, а не наличием компонентов.
